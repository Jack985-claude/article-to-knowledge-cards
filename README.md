# make-knowledge-cards

一个将文章整理为知识卡片的 Codex Skill。它从用户粘贴的内容或本地 Markdown/TXT 文件中提取真正重要、互不重复且可追溯到原文的知识点。

每张卡片包括标题、核心知识、简明解释，以及原文例子或自测问题。文章内容不足时，Skill 会少于 5 张输出，不会为了凑数而编造内容。

## 使用方法

把 Skill 放在 Codex 可发现的 `skills/` 目录后，可在对话中这样使用：

```text
使用 $make-knowledge-cards 将以下文章整理成知识卡片：
<粘贴文章内容>
```

也可以指定本地文件：

```text
使用 $make-knowledge-cards 读取 `notes/learning.md`，生成知识卡片。
```

支持 `.md`、`.markdown` 和 `.txt` 文件；暂不支持网页抓取、PDF、Anki 导出和图形界面。

## 输入输出示例

输入：

```text
间隔学习把复习安排在多次、彼此分开的学习时段中，而不是一次完成。
原文认为，这种安排会让人需要重新提取知识，因此能暴露遗忘的部分。
如果复习间隔过长，学习者可能在复习前完全忘记材料；间隔应随材料难度调整。
```

输出：

```markdown
# 知识卡片

原文只支持 3 个重要且互不重复的知识点，因此不补充无依据的卡片。

## 卡片 1｜间隔学习的安排方式
- 核心知识：间隔学习将复习分布在多个彼此分开的时段，而不是一次完成。
- 简明解释：它描述的是复习的时间安排，而非增加一次学习的内容。
- 例子或自测问题：自测问题：间隔学习与一次完成复习的主要安排差异是什么？

## 卡片 2｜重新提取能暴露遗忘
- 核心知识：分开的复习时段会要求学习者重新提取知识，从而暴露遗忘的部分。
- 简明解释：原文将重新提取与发现需要复习的内容联系起来。
- 例子或自测问题：自测问题：原文认为重新提取能帮助学习者发现什么？

## 卡片 3｜复习间隔需要调整
- 核心知识：复习间隔过长可能导致复习前完全忘记材料，间隔应随材料难度调整。
- 简明解释：原文给出了间隔安排的限制和调整依据。
- 例子或自测问题：自测问题：原文指出哪两项因素会影响合适的复习间隔？
```
